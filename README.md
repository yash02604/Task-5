# Task 6: Host a Static Website with GitHub Pages

## Objective
Deploy a simple static HTML website using GitHub Pages.

## Tool Used
- GitHub Pages

## Project Files
- `index.html` — the main page displayed by the website.
- `README.md` — project documentation.

## Steps Performed
1. Created an `index.html` file for the website.
2. Created a GitHub repository for the project.
3. Pushed the website files to the repository.
4. Opened the repository's `Settings → Pages`.
5. Enabled GitHub Pages and selected the `main` branch and root (`/`) folder as the publishing source.
6. Opened the live website using the URL provided by GitHub Pages.

## Result
The static website is published using GitHub Pages. Website content can be customized with HTML and CSS.
